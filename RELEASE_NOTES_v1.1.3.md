# Release Notes - v1.1.3

**Release Date:** November 21, 2025

## 🐛 Bug Fixes

### Unit Discovery
- **Fixed unit discovery for custom columns** - The application now correctly uses file-specific column mappings when scanning for units. This means if you map a custom column (e.g., "Per Code") to "Units", the application will now correctly discover and list units from that column.

## 📦 Installation

Download the installer for your platform:
- **Windows:** `XLx-Connector-Setup-1.1.3.exe`

## 🔄 Upgrade Notes

This release fixes a logic issue where custom column mappings were ignored during unit discovery.
