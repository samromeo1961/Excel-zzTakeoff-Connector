# Release Notes - v1.1.4

**Release Date:** November 21, 2025

## New Features

### zzTakeoff Window Navigation
- **Menu Bar Added:** The zzTakeoff window now has a dedicated menu bar for easier navigation
- **Back to XLx Connector:** Press `Ctrl+B` or use Navigation menu to focus/reopen the main window
- **Main Window Recovery:** If you accidentally close the main XLx Connector window while zzTakeoff is open, it will automatically reopen when you use the "Back to XLx Connector" option
- **Zoom Controls:** Easily zoom in/out (`Ctrl++/-/0`) from the View menu
- **Quick Navigation:** Menu options for reloading the page and going to the login screen

### UI Improvements
- **Back to XLx Button:** Added a visible button in the zzTakeoff tab toolbar for quick access back to the main window
- **Updated Help Documentation:** Help modal now includes documentation for all new zzTakeoff window features and shortcuts

## Menu Options in zzTakeoff Window

| Menu | Option | Shortcut | Description |
|------|--------|----------|-------------|
| Navigation | Back to XLx Connector | Ctrl+B | Focus main window (reopens if closed) |
| Navigation | Reload Page | Ctrl+R | Refresh the current page |
| Navigation | Go to Login | - | Navigate to zzTakeoff login |
| View | Zoom In | Ctrl++ | Increase page zoom |
| View | Zoom Out | Ctrl+- | Decrease page zoom |
| View | Reset Zoom | Ctrl+0 | Reset to 100% zoom |
| View | Toggle DevTools | F12 | Open/close developer tools |

## Installation

Download the installer for your platform:
- **Windows:** `XLx-Connector-Setup-1.1.4.exe`

## Upgrade Notes

This release enhances the multi-window experience when using zzTakeoff on a second monitor. The main XLx Connector window can now be easily recovered if accidentally closed.
