🔧 Installation Instructions

Follow these steps carefully to install the unsigned beta version:

Step 1: Download the Installer

  1. Download the file Click the download link above to get XLx Connector Setup 1.0.0.exe
  2. Check your Downloads folder The file will be saved to your Downloads folder by default

Step 2: Bypass Windows SmartScreen Warning

🛡️ You WILL see this warning:

"Windows protected your PC - Microsoft Defender SmartScreen prevented an unrecognized app from starting"

  1. Double-click the installer Windows SmartScreen will block the installation initially
  2. Click "More info" Look for the small "More info" link in the SmartScreen dialog
  3. Click "Run anyway" After clicking "More info", a "Run anyway" button will appear. Click it to proceed.

Screenshot Guide:

  1. First dialog: Click "More info" at the bottom
  2. Second dialog: Click "Run anyway" button

Step 3: Complete Installation

  1. User Account Control (UAC) prompt Click "Yes" when Windows asks if you want to allow the app to make changes
  2. Choose installation location The default location is C:\Users\[YourName]\AppData\Local\Programs\excel-zztakeoff-connector
    You can change this if desired
  3. Select options
    • ✅ Create desktop shortcut (recommended)
    • ✅ Create Start Menu shortcut (recommended)
  4. Click Install Wait for installation to complete (usually 30-60 seconds)
  5. Launch the application Check "Run XLx Connector" and click "Finish"

🚀 First Run

When you first launch XLx Connector, you may see another security warning:

🛡️ Windows Defender or Antivirus Warning

Some antivirus software may flag unsigned Electron applications. If this happens:

  1. Click "Allow" or "Run anyway"
  2. Add an exception for XLx Connector.exe in your antivirus settings
  3. The application is safe - it's just not signed with a commercial certificate
✅ Application Should Now Open Successfully

You should see the main XLx Connector window with five tabs: Excel Grid, Recents, History, zzTakeoff Web, and Preferences.

⚠️ Known Issues

  • Unsigned Warning: Windows SmartScreen will always show a warning (this is expected)
  • Large Files: Files over 10,000 rows may take longer to load on first open
  • File Locking: Close the file in XLx Connector before opening in Excel
  • Database Caching: First load creates SQLite cache, subsequent loads are faster

🗑️ Uninstallation

To uninstall XLx Connector:

  1. Open Windows Settings Press Win+I or search for "Settings"
  2. Go to Apps Click "Apps" → "Installed apps"
  3. Find XLx Connector Search for "XLx Connector" or "Excel-zzTakeoff Connector"
  4. Uninstall Click the three dots (⋯) → "Uninstall"

Note: Application data is stored at:

  • Settings: C:\Users\[YourName]\AppData\Roaming\excel-zztakeoff-connector\
  • SQLite Cache: C:\Users\[YourName]\AppData\Roaming\excel-zztakeoff-connector\excel-cache\

🔒 Why Is This Application Unsigned?

Code signing certificates cost $300-$500+ per year and require business verification. For beta testing purposes, we've chosen to distribute an unsigned version to get feedback from testers before investing in a certificate.

Is it safe to run unsigned software?

While you should generally be cautious about unsigned software, this beta is distributed through GitHub from a known source. You can:

  • Verify the source repository on GitHub
  • Review the source code (it's open source!)
  • Check file hashes to ensure integrity
  • Run in a virtual machine if you prefer extra caution

Future releases will be signed once we receive enough positive feedback from beta testers.
