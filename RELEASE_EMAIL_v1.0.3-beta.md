# Beta Release Announcement Email - v1.0.3-beta

---

**Subject:** XLx Connector v1.0.3-beta - Testing Mode Release

---

Hi Beta Testers,

We're excited to announce **XLx Connector v1.0.3-beta**, a special testing release with enhanced flexibility for your testing needs.

## What's New in v1.0.3-beta

This release enables **full testing mode** to give you maximum flexibility:

✅ **Unrestricted File Access** - Open Excel files from any location on your system (no directory restrictions)
✅ **No File Size Limits** - Work with Excel files of any size (unlimited)
✅ **Enhanced Testing Capabilities** - All security restrictions temporarily disabled for comprehensive testing

## Download for Your Platform

### Windows (x64)
**[Download XLx Connector Setup 1.0.3-beta.exe](https://github.com/samromeo1961/Excel-zzTakeoff-Connector/releases/download/v1.0.3-beta/XLx%20Connector%20Setup%201.0.3-beta.exe)**

### macOS (Intel & Apple Silicon)
**[Download XLx-Connector-1.0.3-beta-universal.dmg](https://github.com/samromeo1961/Excel-zzTakeoff-Connector/releases/download/v1.0.3-beta/XLx-Connector-1.0.3-beta-universal.dmg)**
Alternative: [.zip installer](https://github.com/samromeo1961/Excel-zzTakeoff-Connector/releases/download/v1.0.3-beta/XLx-Connector-1.0.3-beta-universal-mac.zip)

### Linux
**Debian/Ubuntu:** [Download XLx-Connector_1.0.3-beta_amd64.deb](https://github.com/samromeo1961/Excel-zzTakeoff-Connector/releases/download/v1.0.3-beta/XLx-Connector_1.0.3-beta_amd64.deb)
**Universal:** [Download XLx-Connector-1.0.3-beta.AppImage](https://github.com/samromeo1961/Excel-zzTakeoff-Connector/releases/download/v1.0.3-beta/XLx-Connector-1.0.3-beta.AppImage)

## Installation Notes

- **Windows:** Run the .exe installer and follow the setup wizard
- **macOS:** Open the .dmg file and drag the app to your Applications folder
- **Linux (.deb):** Run `sudo dpkg -i XLx-Connector_1.0.3-beta_amd64.deb`
- **Linux (AppImage):** Make executable with `chmod +x` and run directly

## We Need Your Feedback!

This testing release is designed to help you work without restrictions. Please test with:
- Large Excel files (any size)
- Files in various locations on your system
- Different construction takeoff scenarios

Report any issues, bugs, or suggestions to help us improve the application.
